# EPHEMERAL

> **"Be present. Leave no history."**

EPHEMERAL is a privacy-first real-time messaging platform designed for casual conversations between friends and groups. 

*"Just like spoken words disappear into memories, digital conversations should disappear too."*

---

## ✨ Features

- **Dark Futuristic Aesthetic:** Deep black voids, neon purple & violet gradients, subtle cyan glances, and glassmorphic surfaces.
- **Bubble-less Floating Messages:** Messages appear directly on the ethereal dark gradient canvas without traditional WhatsApp-style boxed card containers.
- **Decoupled Profile & Chat Interaction:**
  - Clicking any friend or group avatar opens their individual profile.
  - Clicking usernames or conversation titles directly opens the chat room.
- **First-Seen Group Expiration Engine:** In group conversations, the message countdown begins the moment the first recipient views it.
- **Strict Privacy Architecture:** Zero online/offline status dots, zero last-seen timestamps, zero phone number requirements, and zero permanent history.
- **Responsive Layout:** Edge-to-edge mobile web layout with centered container for desktop browsers.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript (Strict Mode)
- **Bundler:** Vite
- **Styling:** Tailwind CSS + Custom Neon Glow Filters
- **Icons:** Lucide React
- **Animations:** Framer Motion & HTML5 Canvas Particle Engine

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone <YOUR_REPO_URL>
cd EPHEMERAL

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📱 Approved Screen Blueprint

1. **Splash Screen:** Pulsing neon infinity brandmark with automated entrance.
2. **Onboarding — Intro:** 3D glowing chat + clock glyph (*"Chat Freely, It Disappears"*).
3. **Onboarding — Features:** Three glassmorphic feature rows (*Privacy First, Your Time, Chat Together*).
4. **Home — Rooms & Friends:** Tabbed room and friend directory with independent avatar/username interactions.
5. **My Profile / Friend Profile:** Reusable `ProfileView` for personal ID and friend cards.
6. **Settings:** Privacy, account, and ephemeral preference configurations.
7. **Private Chat Room:** Floating text chat canvas with countdown badges.
8. **Group Chat Room:** Multi-member conversation with first-seen expiration.
9. **Message Timer Modal:** 1m, 5m, 15m, 30m, and 60m self-destruct durations.
10. **Invite Friends:** Glowing neon chain link graphic and clipboard share chip.
11. **Private Notifications:** Privacy-first alert mockup with zero message preview.
12. **Message Disappearing Animation:** Interactive HTML5 Canvas particle vaporization demonstration.
